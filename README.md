# 🎮 GameHub

A responsive browser gaming website built with **React and Vite**, featuring fun games that work on both desktop and mobile devices.

## 🚀 Live Demo

https://apoorvammaganur792-droid.github.io/gamehub/

## ✨ Features

* 🎮 Multiple browser games
* 📱 Responsive design for desktop and mobile
* ⚡ Fast and lightweight React application
* 🎨 Modern dark gaming interface
* 🕹️ Easy-to-use game controls
* 🔄 Restart and exit options
* 🌐 Deployed using GitHub Pages

## 🎯 Available Games

### 🐍 Snake

Classic Snake game with keyboard and mobile controls.

### 🧱 Tetris

Classic block-stacking puzzle game with scoring and line clearing.

### 🔫 Dark Shooter

A dark anime-style shooter game with:

* Health system
* Ammo system
* Score tracking
* Weapon effects
* Mission-based interface

### 🧠 Memory

A card-matching puzzle game where you test your memory and find matching pairs.

## 💻 Run Locally

Clone the repository:

git clone https://github.com/apoorvammaganur792-droid/gamehub.git

Go to the project directory:

cd gamehub

Install dependencies:

npm install

Start the development server:

npm run dev

Open the local URL shown in the terminal.

## 📦 Build for Production

npm run build

## 🌐 Deploy to GitHub Pages

npm run deploy

The production build is deployed to the `gh-pages` branch.
